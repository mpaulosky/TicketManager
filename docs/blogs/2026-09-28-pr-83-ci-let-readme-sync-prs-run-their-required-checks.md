## ci: Let README sync PRs run their required checks

- **Release tag:** `v0.0.40`
- **Source PR:** [#83](https://github.com/mpaulosky/TicketManager/pull/83)

### PR description

README sync PRs could never merge. `sync-readme.yml` committed with the skip-CI marker in the message, and GitHub skips every workflow when the head commit carries it. So `main`'s required checks never reported on the sync PR. It also pushed with `GITHUB_TOKEN`, which on its own stops workflows from running.

`sync-readme.yml` now matches atelier-store and Blazor-Server:
- it pushes and opens the PR with `RELEASE_PR_PAT`, falling back to `GITHUB_TOKEN`;
- the commit message no longer carries the skip-CI marker;
- the PR title has `[skip-release]`, so a sync doesn't produce a release blog;
- it runs only from `main`, and handles a `docs/README.md` that doesn't exist yet.

`actionlint`, `zizmor` and `yamllint` are clean, and the pre-push gate passed.
