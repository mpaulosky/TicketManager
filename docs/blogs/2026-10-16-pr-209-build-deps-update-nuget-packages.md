# build(deps): Update NuGet packages

- **Release tag:** `v0.0.96`
- **Source PR:** [#209](https://github.com/mpaulosky/TicketManager/pull/209)

## PR description

_Requested by **Matthew** · [project thread](https://claude.ai/code/project/chan_01M4TRjuaTvMLM1jqeNd9KNs?thread=cmsg_01M4TRjuaTvMLM1jqeNd9KNs3RNc9yDo6fauxomeH8GaE4)_

### Why

The NuGet packages had fallen behind their latest stable releases, and the Aspire packages had drifted apart: the AppHost SDK was on 13.5.3 while the packages were spread over 13.4.6, 13.5.2 and 13.6.0. This brings them all up to date and puts every Aspire package and the SDK on one version.

### What changed

`Directory.Packages.props` and the `Aspire.AppHost.Sdk` version in `src/AppHost/AppHost.csproj`. No code changes were needed.

**Aspire (all aligned on 13.6.1)**

- Aspire.Hosting 13.4.6 → 13.6.1
- Aspire.Hosting.Redis 13.5.2 → 13.6.1
- Aspire.Hosting.Testing 13.6.0 → 13.6.1
- Aspire.StackExchange.Redis.DistributedCaching 13.5.2 → 13.6.1
- Aspire.StackExchange.Redis.OutputCaching 13.5.2 → 13.6.1

**Redis client**
