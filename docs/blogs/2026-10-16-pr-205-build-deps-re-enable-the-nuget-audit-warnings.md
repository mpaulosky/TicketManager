# build(deps): Re-enable the NuGet audit warnings

- **Release tag:** `v0.0.94`
- **Source PR:** [#205](https://github.com/mpaulosky/TicketManager/pull/205)

## PR description

### Why

`Directory.Packages.props` turned off NU1902 (moderate) and NU1903 (high) for transitive MongoDB.Driver 3.8.0 dependencies. Nothing vulnerable is left from those, but the suppression still hid new advisories: MessagePack 2.5.302 (GHSA-qhrr-8q5h-9q3h) went unreported until #203 pinned it.

### What changed

- `Directory.Packages.props`: remove the `NoWarn` for NU1902 and NU1903 and its comment. NU1901 (low) and NU1904 (critical) were never suppressed.

TicketManager doesn't set `TreatWarningsAsErrors`, so an advisory shows up as a restore warning and doesn't fail the build.

### Verification

- With the audit on, `dotnet restore --force` reports no NU190x warnings, and `dotnet list package --vulnerable --include-transitive` reports no vulnerable packages.
- The pre-push gate passed.
