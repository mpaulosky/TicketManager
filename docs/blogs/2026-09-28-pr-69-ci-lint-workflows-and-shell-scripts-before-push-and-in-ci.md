## ci: Lint workflows and shell scripts before push and in CI

- **Release tag:** `v0.0.35`
- **Source PR:** [#69](https://github.com/mpaulosky/TicketManager/pull/69)

### PR description

Brings over the workflow and shell lint that atelier-store runs (mpaulosky/atelier-store#10), and fixes everything it found on `main`.

## New checks

- **`lint-actions.yml`** runs three jobs: `actionlint` (workflow syntax and expressions, plus shellcheck on every `run:` block), `zizmor` (workflow security audit; fails on medium or above), and `shellcheck` (shell scripts and git hooks). All three are pinned.
- **`scripts/gate.sh`**, run by the pre-push hook, lints the Markdown, YAML, workflow and shell files changed since `origin/main`, builds the solution, then runs each test project. It keeps the hook's existing test loop, including its fallback runner.
- **`pre-push`** now checks the refs actually being pushed rather than the checked-out branch. It refuses to push a commit that isn't checked out, and refuses a dirty working tree, because the gate tests the working tree. Branch naming rules are unchanged.

## Fixes to what the linters found

- **Every action is pinned to a commit SHA**, with the tag kept as a comment. The SHAs match atelier-store's.
- **`code-metrics.yml`:**
  - `if: ${{ … }} == 'true'` was always true.
  - The dispatch `reason` was interpolated straight into a shell script.
  - The workflow has never run on push or PR: a `paths:` filter with only `!` patterns matches nothing. It's now explicitly manual-only, using atelier-store's hardened version.
- **`ci.yml`:**
  - The default token is now read-only; only the report job gets `checks`/`pull-requests: write`.
  - Matrix values go through `env:` instead of being interpolated into scripts.
  - The job summary uses a single grouped redirect.
- **Checkout credentials:** `persist-credentials: false` on every checkout that doesn't push. The jobs that do push (release, sync-readme, generate-blog-posts-json, squad cleanup) carry a documented `zizmor: ignore[artipacked]`.
- **`dependabot-auto-merge.yml`:** its `pull_request_target` trigger is documented and ignored, since the job never checks out PR code.
- **Dependabot:** 7-day cooldown on every ecosystem.
- **Smaller fixes:**
  - `pre-commit`: `cd "$ROOT" || exit 1` (SC2164).
  - `release.yml`: quote the `BUMP` values (SC2209).
  - `.gitignore`: add `.tmp-test-results/`, where the gate writes test results.

## Validation

- `actionlint`, `zizmor` (online audits included), `yamllint`, and `shellcheck` are clean.
- The pre-push gate passed (build and every test project).
