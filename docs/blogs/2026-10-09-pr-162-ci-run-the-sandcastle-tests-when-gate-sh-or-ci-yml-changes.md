## PR description

### Why

Claude Review flagged this on #158 after it merged. The Sandcastle check's path list leaves out the two Template-owned files that call the tests: `scripts/gate.sh` (the pre-push gate) and `.github/workflows/ci.yml` (Build Solution, which also picks the runner and so the Node the tests run on). A Baseline re-Apply that changes either one would skip the Sandcastle tests on its own PR, and the breakage would first show up on main.

### What changed

- `.github/ci/sandcastle.sh` adds `scripts/gate.sh` and `.github/workflows/ci.yml` to `SANDCASTLE_PATHS`, and its comment says why they're there.
