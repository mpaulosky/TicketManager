## ci: Run the test suite on Dependabot PRs

- **Release tag:** `v0.0.39`
- **Source PR:** [#80](https://github.com/mpaulosky/TicketManager/pull/80)

### PR description

`ci.yml` skipped test discovery, every test job, coverage and the report job whenever Dependabot opened the PR. GitHub counts a skipped check as passing, so the required "All Tests Passed" check went green on Dependabot bumps without a single test run. #75 (15 NuGet updates) was only tested because its branch fell behind `main` and was updated under a user account. No test here needs a secret, so they now run on Dependabot PRs too.

Dependabot runs always get a read-only `GITHUB_TOKEN`, so the step that publishes the "Test Results Summary" check run and PR comment still skips there. "All Tests Passed" still fails when any test did.

Validation: `actionlint`, `zizmor` and `yamllint` are clean, and the pre-push gate passed.
