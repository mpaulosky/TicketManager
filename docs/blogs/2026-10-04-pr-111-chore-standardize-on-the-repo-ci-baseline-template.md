# chore: standardize on the repo-ci-baseline Template

- **Release tag:** `v0.0.49`
- **Source PR:** [#111](https://github.com/mpaulosky/TicketManager/pull/111)

## PR description

This PR brings TicketManager onto the shared CI, release and hook Baseline. It Applies the `repo-ci-baseline` Template from dotfiles, then adapts the repo to it.

### What changed

- **Apply** (`chore: apply repo-ci-baseline Template`): the script's output, unchanged.
  - CI, release, auto-merge, lint and CodeQL workflows.
  - Git hooks and `scripts/gate.sh`.
  - The Seed docs.
- **Template fixes, re-applied here:**
  - mpaulosky/dotfiles#27: `release_post.py` now rebases README's relative links when it copies README into `docs/README.md`. Without it, the first release would undo #104.
  - mpaulosky/dotfiles#29: `backfill_blog_posts.py` refreshes `docs/README.md` even when no post is owed, and `codecov.yml`'s status checks sit under `coverage`, where Codecov reads them.
  - mpaulosky/dotfiles#30: `load_test_env.py` refuses `NODE_OPTIONS`, which the runner won't export. `.claude/settings.json` leaves the Template, because Claude Code permissions are set per user, so this PR deletes it.
  - mpaulosky/dotfiles#28: the pre-push gate no longer passes git's hook environment on to the tests. Before, `GitCommandRunnerTests` read the pushing repo from its temp folder and failed the push from a worktree.
- **Leftovers deleted:**
  - The auto-merge decision module, its test and `automerge-tests.yml`. The Template keeps that decision inline.
  - `label-enforce.yml`, which applied squad's triage labels.
  - `sync-readme.yml`, `docs_readme.py`, its test and `docs-readme-tests.yml`. `release_post.py` now maintains `docs/README.md`.
- **Pages site on the Template's model:** `docs/index.html` used to fetch releases from the GitHub API and posts from `docs/data/blog-posts.json` in the browser.
  - The two lists are now `RELEASES_HTML` and `BLOGS_HTML` marker blocks that `release_post.py` fills at each release. They're styled to match the page and already filled with the current 10 releases and posts.
  - Deleted: the fetching script, `generate-blog-posts-json.yml`, its script and the JSON file.
- **Copied-in agent files deleted:**
  - `.github/skills` and `.github/prompts`.
  - All of `.github/instructions` except the Template's `blog`, `git-commit` and `markdown`.
  - Most came from other repos, such as IssueManager's `build-repair`, a MediatR and MongoDB `vertical-slice`, and `mongo-dba`.
- **Markdown lint on:** `.markdownlint.json` had switched every rule off. It's gone, the auto-fix has run, and the overlong lines are wrapped. `docs/releases/Test.md`, a throwaway file, is removed.
- **Docs:** `SECURITY`, `REFERENCES` and `CONTRIBUTING` described AINotesApp and a `develop` branch. They now describe TicketManager and `main`. They also describe Auth0 sign-in as planned, since no authentication handler is registered yet.
- **Repo setup:**
  - `prepare.sh` installs the Web project's pnpm packages for the Tailwind build, and writes the install stamp so the csproj doesn't install them a second time.
  - Per-project `.gitignore` files cover `app.css` and `appsettings.Development.json`.
  - `.aspire/settings.json` is committed.
