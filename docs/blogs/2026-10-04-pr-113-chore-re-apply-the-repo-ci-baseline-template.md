# chore: Re-apply the repo-ci-baseline Template

- **Release tag:** `v0.0.50`
- **Source PR:** [#113](https://github.com/mpaulosky/TicketManager/pull/113)

## PR description

### Why

TicketManager is the first repo to get today's Baseline changes, as the live check of each one before they reach the other repos (dotfiles #31–#36). It was the only repo identical to the Template, so this re-Apply contains only those changes.

### What changed

**Apply** (`chore: Apply repo-ci-baseline Template`, the script's output alone):
- **Worktrees:** `pre-commit` refuses commits in the main checkout; every change goes in a worktree under `../TicketManager-worktrees/`.
- **New required checks:**
  - **Branch name** (`ci.yml`, sharing `scripts/check-branch-name.sh` with `pre-push`);
  - **PR title** (`pr-title.yml`, the commit format).
- **Auto-merge:** re-checks a PR when a review is submitted (`pr-review-submitted.yml`), and sweeps off the round minutes.
- **One written process:** `docs/PROCESS.md`, plus a PR template.
- **Dependabot:** GitHub Actions bumps skip the build and tests; NuGet and SDK bumps still build.
- **Smaller changes:** `discover_tests.py` evaluates a `Condition` on `IsTestProject`; the release and backfill PR titles are capitalized; the code-metrics PR gets a commit-format title; the release tag step stops at a rejected push.

**Adapt:**
- `CONTRIBUTING.md`: the Quick Start, branch table, commit tips and review process now link to `PROCESS.md`. The old review section said maintainers approve and merge, which auto-merge contradicts.
- `.github/copilot-instructions.md`: points to `PROCESS.md`.
- `dependabot.yml`: the `chore(deps)` commit prefix for all four ecosystems.

**GitHub settings** (`github-settings.sh --fix`, first pass, already applied):
- squash only, with PR title + body as the commit;
- pinned actions required;
- `code_quality` rule removed; `markdownlint` and `yamllint` now required;
- `sandcastle:needs-human` label created.

The second pass, right after this merges, adds **Branch name** and **PR title** to the required checks.

- **`github-settings.sh` after pass 1:** clean, apart from the two checks that wait for this merge.
