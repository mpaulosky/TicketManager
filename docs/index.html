Early-stage · .NET Aspire · Blazor

Manage GitHub Issues through GitHub Projects.

TicketManager is a developer-focused app for working with GitHub Issues inside GitHub Projects while keeping GitHub itself as the system of record. The repo is early in its journey, with a clean Aspire scaffold, a Blazor front end, and strong docs-first engineering habits.
